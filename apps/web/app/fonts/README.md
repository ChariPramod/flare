# Local typefaces

Flare serves these unmodified Latin variable font subsets through `next/font/local`.
Builds and page views require no font-service requests. Other scripts use system fallbacks.

- **DM Sans**, weight 100–1000, normal; Fontsource package `@fontsource-variable/dm-sans` 5.3.0.
- **Source Serif 4**, weight 200–900, normal and italic; Fontsource package `@fontsource-variable/source-serif-4` 5.3.1.

The files come from each package's `files/*-latin-wght-*.woff2` assets on the npm registry.
Each typeface's SIL Open Font License is included beside the font files. Keep these notices when redistributing the assets.
