# Learning memory

This directory can hold optional teaching context for explaining Flare through a continuing story. A local `flare-story.md` may preserve a reader's preferred characters, metaphors and earlier explanations; it is not required to run or contribute to the project.

Learning notes are not implementation status or acceptance evidence. Before explaining current work, check [current progress](../../PROGRESS.md), recent Git history and the relevant implementation, then use the [acceptance ledger](../development/acceptance.md) to distinguish what is implemented, tested and deployed. A storytelling preference or request alone does not authorize code changes or deployment.

Use the [website and backend guide](../product/website-and-backend-guide.md) for the ordinary project tour and the [documentation index](../README.md) to find technical guides.
