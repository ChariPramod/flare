# HTTP contract

`openapi.json` is generated by `pnpm openapi:generate` after dependency builds and served at the API's `/docs` and `/docs-json` endpoints. `pnpm openapi:check` verifies that generated files match controllers and response mappings. Native Postal/SNS/Novu callbacks use the signed raw body; they are not API-key endpoints. Session-only operations declare session authentication separately.

Use the generated SDK for typed path/query/body inputs. JSON payload schemas and provider/engine-specific response fragments intentionally permit flexible JSON. Business constraints that JSON Schema cannot represent (tenant ownership, combined recipient totals, sender verification, version dependencies and state transitions) are enforced by the API.
